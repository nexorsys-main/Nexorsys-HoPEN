1. Introduction & Vision Stratégique

La Suite NexorSys Identity + Kiosk est une solution de gouvernance des identités (IAM) et de sécurisation des accès terminaux conçue spécifiquement pour des environnements partagés (chariots de soins, urgences, entreprises). Le sous-système Vault intégré (1.5.2) protège les identifiants partagés par un chiffrement de niveau entreprise (AES-256-GCM).

Objectif : Remplacer le login classique par une authentification forte "Tap-to-Login" (Badge NFC + PIN) en moins de 3 secondes.

2. Architecture Backend (.NET 8)

Le backend centralise toute la logique métier et sert de source de vérité unique (SSOT).

Composants Clés :

  • LdapService.cs : Gère la synchronisation bidirectionnelle avec l'Active Directory. Importe les agents et vérifie les credentials AD.
  • KioskAuthController.cs : Endpoint haute performance pour le handshake sécurisé avec les clients WPF.
  • AuditService.cs : Enregistre chaque événement de sécurité via des requêtes SQL natives pour garantir une traçabilité immuable.

Points d'API Critiques :

POST /api/auth/login        // Accès Dashboard DSI
POST /api/kiosk/auth       // Validation Badge + PIN
GET  /api/users/search     // Recherche hybride SQL/LDAP
POST /api/kiosk/reset-pin  // Révocation de sécurité

3. Dashboard Identity (React / Vite)

Interface d'administration pour la DSI permettant la supervision globale.

Fonctionnalités :

  • Gestion des Agents : Enrôlement des badges NFC et configuration des codes PIN.
  • Piste d'Audit : Visualisation temps réel des accès par service et par agent.
  • Contrôle RBAC : Attribution granulaire des accès applicatifs (BlueKango, EMED, etc.).

Technologie : React 18, Tailwind CSS (Glassmorphism), Lucide Icons.

4. Client Pinède NFC (WPF / .NET 8) Lockdown Layer

Le client lourd Windows qui transforme un PC standard en kiosque sécurisé.

Logiques Locales :

  • NfcService.cs : Monitoring permanent des lecteurs PC/SC via la pile native PCSC-Sharp.
  • Windows Lockdown : Masquage total de la barre des tâches et interception des raccourcis système (Alt+F4, Ctrl+Esc).
  • Secure Storage : Aucune donnée sensible n'est persistée localement ; tout transite par des flux JWT signés.

6. Sécurité & Conformité

Standards Appliqués :

  • eIDAS Substantiel : Authentification MFA (Possession + Connaissance).
  • BCrypt Hashing : Protection contre les attaques par force brute sur les bases de données.
  • JWT Tokens : Jetons de session signés avec une clé de 2048 bits (RSA).
  • Smart App Control : Binaires signés numériquement pour Windows 11.

7. Logiques d'Intégration Systèmes

Protocole URI Custom (nexorsysnfc://)

Permet au Dashboard Web de piloter l'application locale Windows. En cliquant sur une action web, le navigateur invoque le registre Windows pour lancer ou configurer le Kiosque NFC à distance.

8. Déploiement & Maintenance

Le déploiement est automatisé via des scripts PowerShell :

  • Setup-Database.ps1 : Initialisation du schéma PostgreSQL.
  • Sign-App.ps1 : Signature cryptographique des exécutables.
  • Install_Application.ps1 : Déploiement MSI sur les terminaux de soins.
