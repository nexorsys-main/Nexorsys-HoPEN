Briefing Technique : NexorSys Identity + Kiosk (1.5.2)

Dossier de Présentation Technique & Fonctionnelle v1.1

1. Architecture Globale

Le système est composé de deux piliers technologiques synchronisés :

  • Pinède Identity (Web) : Un backend .NET 8 et un dashboard React assurant la gestion centralisée des identités (IAM).
  • Pinède NFC APP (Desktop) : Un client WPF .NET 8 local sécurisant les terminaux de soins (Kiosques).

2. Pinède Identity Platform

Noyau Backend API

Le backend agit comme la source de vérité unique (SSOT). Il gère :

  • Liaison Active Directory via LDAP/LDAPS.
  • Authentification forte 2FA (Badge + PIN).
  • Génération de jetons JWT sécurisés.
  • Journalisation d'audit centralisée en base PostgreSQL.

3. Pinède NFC APP

Le Bouclier Local

Application installée sur les chariots de soins et postes d'urgence :

  • Mode Kiosque : Verrouille totalement Windows.
  • Lecture NFC : Intégration matérielle PCSC (Mifare/Desfire).
  • Zero Trust : Aucune donnée stockée localement ; validation temps réel via API.
  • Smart Launcher : Bureau restreint n'affichant que les applications autorisées (Hestia, BlueKango, etc.).

4. Logiques de Sécurité

Le Handshake 2FA

1. L'agent passe son badge (Facteur Possession).
2. L'agent saisit son PIN (Facteur Connaissance).
3. L'API valide le couple via cryptographie BCrypt et renvoie un token JWT.
