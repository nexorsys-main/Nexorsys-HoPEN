Exigences & Prérequis

Environnement Hôte

  • OS Cible : Windows 10 / 11 (64-bit)
  • Pas de droits administrateurs requis pour l'exécution (hors installation)
  • Déploiement possible en mode "Self-Contained"

Matériel & Infrastructure

  • Lecteur NFC PC/SC USB (ex: ACR122U)
  • Badges : Mifare Classic / ISO14443
  • Accès réseau vers le Contrôleur de Domaine (port 389 ou 636)
Objectif d'infrastructure :
Créer une application lourde performante, gérant l'accès bas niveau au port USB (PC/SC), et capable de dialoguer nativement avec Kerberos / LDAP sur le domaine local.

Cœur Technique

Développement et Architecture Logicielle

.NET 8 & WPF

Cadre de développement lourd performant. Compilation JIT ou ReadyToRun. Fenêtres XAML pour un rendu riche et fluide.

Architecture MVVM

Séparation stricte UI/Logique via CommunityToolkit.Mvvm. Modèles de vues observables (INotifyPropertyChanged automatisé).

Injection de Dépendance

Microsoft.Extensions.Hosting pour gérer le cycle de vie des services (NfcService, AdService, DialogService).

Chiffrement AES-256 Intégré

Le ServiceChiffrement.cs chiffre à la volée le mot de passe compte de service avant son écriture dans appsettings.json, verrouillant la payload cryptographique sur l'identifiant unique de la machine locale (antivol).

Interopérabilité

Processus AD et PC/SC Windows

Couche Basse PC/SC

  • Utilisation de PCSC-Sharp pour communiquer au niveau matériel avec l'API SmartCard de Windows.
  • Monitoring Asynchrone : Émission d'Apdu `FF CA 00 00 00` pour requêter l'UID ISO-14443-A.

Résolution LDAP

  • Bibliothèque System.DirectoryServices.AccountManagement.
  • Bind SSL (LDAPS 636) optionnel selon le panenau admin.
  • Validation renforcée avec appartenance obligatoire à un Security Group (ex: GroupeRestreint).

Système

Flux de Déploiement CI/CD & Scripting

L'application est packagée pour être autonome ou persistante de manière robuste.

1. Publication "Portable"

  • Script batch : Publish_Portable.bat
  • Commutateur : --self-contained true
  • Inclus la CLR .NET 8, pas besoin d'installateur sur la machine clinique cible. C'est du "Xcopy Deployment".

2. Signature Root CA

  • Le script Install_Application.ps1 installe un certificat auto-signé "Clinique La Pinede" dans le Root CA de Windows.
  • Bypass légitime de Smart App Control (SAC) sur Windows 11.
Kiosque Persistant (Auto Start) :
Depuis l'IHM admin, une règle inscrit l'app dans le registre `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. Ainsi, même lors des redémarrages serveur automatisés pour WSUS, l'interface NFC s'ouvre d'office.

Une réponse technique de pointe pour le terrain

  • Couche locale forte (.NET 8 WPF) pour la réactivité (0 latence HTTP)
  • Couplage système parfait pour la lecture matérielle directe
  • Protection de la donnée credential par cryptographie moderne
  • Conception sans dette technique, prêt à évoluer !
